# A disciplina

SMAC03 – Grafos, Prof. Rafael Frinhani, UNIFEI 2026/2. Fonte: *Diretrizes do Projeto 2026.2*.

O trabalho é em grupo, mas a nota é individual. Todos apresentam, e o relatório precisa deixar claro o papel de cada um.

## O que é avaliado

1. **Entender** o problema do cenário sorteado.
2. **Modelar** o problema como grafo e escolher métodos de grafos para resolvê-lo.
3. **Desenvolver** um protótipo que recebe o dataset e devolve a solução. Interface gráfica é opcional; o que conta é o núcleo algorítmico.
4. **Validar** o método com métricas quantitativas e discutir resultados, limitações e melhorias.

## Lições do trabalho de referência (2024, nota 7/8)

O que o grupo decidiu copiar: equação com "onde:" definindo cada símbolo, tabela de parâmetros, dois algoritmos comparados no mesmo cenário, escala de cores explicada, link do GitHub no texto.

O que evitar: resultados só qualitativos, introdução sem pergunta e hipóteses, espaço gasto com conteúdo que não é grafo, figuras repetidas, imprecisão sobre o que cada algoritmo garante, erros de digitação e referências cruzadas erradas. Essas causas do desconto são inferência do grupo, não feedback do professor.
